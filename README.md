
# Personal Portfolio Website — Matiur Rahman Limon

A simple, clean, and responsive personal portfolio website developed for **Matiur Rahman Limon**, a Bachelor of Pharmacy (B.Pharm) student.

This project was built to showcase his personal introduction, educational background, and contact information through a minimal and user-friendly website.

## 🌐 Live Website

[Visit Portfolio Website](https://matiur-portfolio.onrender.com)

## ✨ Features

- Clean and modern user interface
- Responsive design for different screen sizes
- Personal introduction and profile section
- Educational background
- Contact information
- Smooth navigation

- CSS3
- JavaScript
